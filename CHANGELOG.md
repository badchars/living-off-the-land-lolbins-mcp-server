All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-17

### Added

- Initial release with 59 composite tools and 321 total tools
- 10 LOL catalog integrations (GTFOBins, LOLBAS, LOOBins, LOLDrivers, LOLRMM, LOLESXi, LOTP, LOLC2, LOFLCAB, WADComs)
- Attack graph reasoning with BFS/DFS path finding
- Environment enumeration (Linux, Windows, macOS, ESXi)
- Privilege escalation path discovery
- Defense evasion and obfuscation techniques
- Detection engineering (Sigma, YARA, Sysmon, EDR queries)
- MITRE ATT&CK mapping and Navigator export
- Purple team exercise generation
- MITRE Caldera profile export
- Threat actor mapping and adversary simulation
- Forensic artifact analysis and incident timeline correlation
- Red vs Blue team scoring
- Report export (JSON, Markdown, CSV, ATT&CK Navigator)
- Attack path visualization (Mermaid, Graphviz, ASCII)
- CLI with --list, --list-all, --help, --tool flags
- README translations in 23 languages
